## 説明文 FAQ（本文のあとに貼る）

このブロックごと貼る:

```
よくある質問

SKU-0 とは何ですか？
自分の n8n に入れる受付スターターです。フォームまたは webhook が、自分で管理する表に1行書きます。通知スタブが人に知らせます。送るのは人です。自動返信はありません。

n8n は先に必要ですか？
はい。自分で管理する n8n Cloud またはセルフホストが必要です。この配布はテンプレートであり、ホスティングではありません。n8n の契約代行や、名義でのアカウント作成はしません。

メールやチャットを代行送信しますか？
しません。通知は人への ping です。送信は人のままです。自動返信、自動請求、名義での自動投稿はありません。

zip にパスワードや API キーは入っていますか？
入っていません。接続名だけで、秘密の値は空です。鍵は n8n の画面で自分で入れます。チャットや共有メモに秘密を貼らないでください。

SKU-1 / SKU-2 / SKU-3 は必要ですか？
不要です。SKU-0 だけで使えます。分類・承認ゲート・シート同期は、出すときは別商品です。この zip に入っていると思わないでください。

AI は入っていますか？
入っていません。スタブは振り分けと通知だけです。あとからモデルを足す場合も、確定は人です。AI 無しならスタブのままで構いません。

n8n や Gumroad の関係者ですか？
違います。個人の出品です。n8n、Gumroad、Google、OpenAI、xAI のパートナー／社員ではありません。ツール名は道具であり、徽章ではありません。

自分の n8n の版で読み込めないときは？
キャンバス上の付箋どおりに組み直してください。スタブは手順のグラフであり、版固定の製品ではありません。連絡は n8n の版だけ。秘密は送らないでください。
```
