# HANDS + ToS — Freelancer.com surgical-bid (no auto-bid)

**HANDS** means: you read **one** listing, you rewrite the one specific line, you paste in the official bid form, you click Bid. A computer must not be the thing that submits.

**Surgical** means: **one listing per style file**, then stop. Leftover monthly bids are not a reason to send another. Identical first paragraphs across projects are spray.

Default: **do not send**. This pack does not sign up, fund a wallet, or click Bid.

## Forbidden in this pack (do not add later either)

Do **not** write or run:

- Auto-apply / auto-bid / “use remaining bids this month” queues
- Browser automation, headless browsers, scrapers, or extensions that submit faster than a person
- Freelancer API / MCP use to spam bids or scrape projects
- Multiple accounts to dodge bid limits
- Sponsored / Highlight / Sealed bids as a default tactic
- Contests (including “free to enter”) from this pack
- Preferred Freelancer exam / Recruiter-only rows from this pack
- Contact info (email, phone, WhatsApp, Telegram, Slack) in a pre-award bid
- Off-platform payment instructions
- Live USD amounts committed in git
- Fee tables, membership prices, or bid-upgrade prices copied from anywhere — **fees page URL only**

Native “saved replies” (if the UI shows them) are still templates you insert by hand; personalize `{{ONE_SPECIFIC_DETAIL}}` before send.

## Fees (URL only)

Do **not** invent fees. Do **not** paste the schedule into a bid or into git as a payment plan.
