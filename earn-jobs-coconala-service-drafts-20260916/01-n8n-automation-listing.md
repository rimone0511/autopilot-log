## 4. サービス内容（1000 字以内。フェンス内を貼る）

買い手向け。ここに「未公開ドラフト」と書かない。

```
毎日のコピペや転記を、依頼者の n8n Cloud またはセルフホスト上のフローにします。公式の API と webhook だけを使います。ブラウザ操作、スクレイピング、いいね・フォロー・閲覧の自動化はしません。

向いている例: フォームの行を表へ足して人に知らせる、下書きメールを作って承認が付くまで送らない、失敗したら人に戻して再実行する。向いていない例: 公式 API が無い画面の操作、権利のない投稿の無人公開。

納品
- スコープ済みフロー 1 本（読み込み用 JSON）
- 手順書（何をするか、失敗したときどう戻すか、秘密の欄と編集してよい欄）
- 接続名の一覧（値は書かない）
依頼者の版で JSON が読み込めないときは、手順書どおりキャンバス上で組み直します。

進め方
1. いま手でやっている手順を、入力・出力・止める条件に分ける
2. 公式コネクタでフローを 1 本組む
3. 成功パスと失敗 1 件を試す
4. 手順書を渡す。本番のスイッチは依頼者が入れます

AI の分類・要約・下書きは、依頼があったときだけ足します。無しでよい場合はモデル呼び出しを入れません。こちらが代わりに送信や公開はしません。

含まれないもの: n8n の契約代行、鍵の代理入力、税務・法律の断定、成果や時短の保証。やり取りはココナラのトークルームだけです。

```
