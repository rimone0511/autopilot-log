# HANDS + ToS — no off-platform pay

Status: **DRAFT_ONLY**. 人が公式 UI に貼る。ボットで応募・発行しない。

**HANDS** = 画面を読む → このパックを貼る → 公開ボタンは人が押さない（下書き保存まで）。提出スクリプトは置かない。

## Forbidden in this folder

- サイト外の支払い（現金、銀行振込、PayPal、暗号、別サイトの請求書）
- メール / 電話 / LINE / WhatsApp / Slack を **契約前の本文・プロフィール・チケット** に書く
- 中抜き・直接取引の勧誘
- 自動応募、同一文面の大量送信、スクレイピング
- 第二アカウント
- 料金・手数料の創作、売上実績の創作

## TimeTicket

公式:

- [ホストの禁止行為](https://help.timeticket.jp/articles/19400)
- [利用規約](https://www.timeticket.jp/terms)（中抜きの禁止を含む）
- [通常チケット](https://help.timeticket.jp/articles/19374)

禁止の要旨（ヘルプ 19400）:

- 中抜き、現金取引（手渡し・銀行振込）の要求・承諾
- タイムチケットを使わずに類似サービスを合意すること
- チケット代・オプション以外の代金をゲストに別途要求
- 本文・画像・URL にメール・電話・住所など個人を特定しうる情報

このパック: やり取りは **メッセージ（非同期）**。Zoom/電話/対面を付けない。承認後のツール詳細も公式 DM に残す（ヘルプ 19387 の流れ）。LINE をチケットに書かない。

同じ内容のチケットを複数発行しない。

Invoice / proposal は公式 `https://contra.com/proposal/new`。このフォルダからは送らない。Free のまま。Pro を手数料対策で買わない。

## クラウディア

公式:

- [直接取引について](https://www.craudia.com/faq/contents/164)
- [利用規約](https://www.craudia.com/app/agreement)
- [仕事依頼ガイドライン](https://www.craudia.com/project_guideline)（連絡先投稿・指定口座への振込などの NG 例）

要旨:

- サイトを介さない依頼・受注・金銭取引は直接取引として禁止
- 規約: 原則サイト外の直接契約不可。違反時の違約金規定あり（報酬の 30%、下限 100万円 — **数字は規約本文を正とする。ここでは警告だけ**）
- 外部ツール連絡は原則禁止。必要なときだけ公式のサービス外連絡申請
- プロフィールや応募にメール・電話・「この口座へ」を書かない

このパックは応募もスキル出品もしないので、メッセージ発生前に止まる。
