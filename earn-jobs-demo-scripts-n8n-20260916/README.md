## How a take is built

Each file has the same layers. **Do not** put the fact table on camera.

| Layer | Lives in | On camera? |
|---|---|---|
| Fact table | Markdown above the fences | no |
| Shot list | numbered table | operator only (or as a private checklist) |
| Spoken EN | fenced `Spoken EN` | yes, if the buyer is EN |
| Spoken JA | fenced `Spoken JA` | yes, if the buyer is JA |
| On-screen captions | short lines | optional burned-in; keep dummy |
| Close questions | two questions, no quote | yes |

Length target: **90–120 seconds** spoken. If the live counter / Loom timer runs long, cut the “what you would own” block, keep the dummy run and the two questions.

Measured this pack (`len` of the Spoken EN / Spoken JA fences, placeholders unsubstituted, 2026-09-16):
