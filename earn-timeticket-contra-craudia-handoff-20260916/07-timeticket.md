## Google / signup preference

優先: 公式が案内する **メール登録**。メールは `{{GOOGLE_ACCOUNT_EMAIL}}`（MAIN Google。別アドレスを作らない）。

OTP / 本登録リンク: **親の Gmail**。CU ブラウザで `mail.google.com` を開かない。

使わない:

- この GO のために LINE / Apple / Facebook を新規作成すること
- 「別のアカウントを使う」
- 電話相談チケット（リアルタイム通話。async ではない）

Google ボタンが **ある** ときは MAIN Google で押してよい。無いときはメール。LINE しか無くメールが不可能なら **STOP**（朝の本人へ。ランダム SNS を縛らない）。

## CU 手順（下書き）

1. https://www.timeticket.jp/ を開く。ホスト側のユーザー登録。
2. メール = MAIN Google。届いた確認は親 Gmail。
3. プロフィールを下の field map で埋める。規約第8条: 設定を変えないとプロフィールは公開される → **非公開 / 非表示があれば必ずオフ**。
4. 本人確認（`identifications/edit`）が出たら **アップロードしない**。[STOP-KYC.md](STOP-KYC.md) の朝メモだけ書いて次へ。
5. チケット: 通常チケットの下書き。形式は **メッセージのみ**（公式ヘルプ: 対面 / オンライン / 電話 / メッセージから選ぶ。複数可だが **このパックはメッセージだけ**）。エリアは **インターネット**。
6. **発行して予約可能日時の登録へ** と **チケット発行手続きを完了する** は公開相当として押さない。画面に下書き保存があればそれを使う。無ければチケットは作らずプロフィールで完了。
7. チケット作成が本人確認必須ならチケットは作らない。プロフィールのみ。

やらない: SNS シェア、LINE 公式連携、予約枠の公開カレンダー埋め、同じ内容の複数発行（ホスト禁止行為）。
