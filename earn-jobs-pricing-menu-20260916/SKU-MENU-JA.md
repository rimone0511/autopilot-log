## 含むもの / 含まないもの

### n8n starter

**含む**

- トリガー 1 つ（フォーム、Webhook、または表の行）
- 表（または同等の置き場）へ 1 本のパスで書く
- 人への通知（メール / チャット / 表。依頼者が選ぶ）
- 短い手順: 何が始まるか、どこを直すか、秘密の置き場、再実行
- 公式コネクタ / 公式 API / Webhook のみ

**含まない**

- 自動返信・自動送信・無人の公開投稿
- 分類ラベル、承認ゲート（それらは別 SKU）
- ブラウザ自動操作、スクレイピング、いいね / フォロー / 閲覧の自動化
- n8n のホスティング購入
- 精度 %、SLA、売上保証

### classifier

**含む**

- 依頼者がすでに使っているラベルへ、inbound を割り当てる
- 迷ったものは **未確定 / ホールド**
- 人への通知。送信ボタンは人
- スタブまたは同等の手順（Gumroad は inactive JSON）

**含まない**

- 自動返信、自動請求、名義での投稿
- ラベル精度の数値保証
- 承認してから外に出すゲート（それは approval-gate）
- AI 必須。スタブでは AI オフ。後から足すなら人が見る

### approval-gate

**含む**

- 外に出す前に人の **approve** が必要
- reject / 欠落 / 不明 / タイムアウトは **閉じる**（勝手に送らない）
- 承認後の通知経路の型（実送信ノードは依頼者の n8n に置く。こちらの下書きは NoOp）
- 失敗時の短いメモ

**含まない**

- タイムアウトで自動送信
- ライブの送信認証情報
- 会社全体の承認基盤
- SLA（何分以内に承認、など）

### docs

**含む**

- 既存の 1 フロー（または依頼者が渡した画面）向けの手順書
- 再実行、秘密と編集してよい欄の区別、失敗したときの順
- 必要なら変更メモ（何を変えたか、何を再試験するか）
- 日本語、または日英の短い対訳（依頼者が選ぶ）

**含まない**

- 新しい n8n フローの構築（それは starter / classifier / approval-gate）
- ソースコード一式、関係ない製品の内部
- ホスティング契約の代行

### 四 SKU 共通でやらないこと

- ブラウザ自動操作・スクレイピング
- いいね、フォロー、閲覧、コメントの自動化
- 権利のない投稿代行、無人の SNS 公開
- パスワード・API 鍵・本人確認の代理入力
- n8n / ココナラ / Gumroad / Contra / AI ラボの公式パートナー表示
- シート同期パック（SKU-3）— このメニューの外。別パック
