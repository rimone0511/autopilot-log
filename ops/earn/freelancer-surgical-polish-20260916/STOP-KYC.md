## Official path (do not complete from this pack)

Identity Policy: **Verified by Freelancer** asks for:

1. **Proof of identity** — government-issued photo ID (policy lists passport / driver’s license / national ID). Account name must match the ID.
2. **Keycode verification** — photo of you holding a unique code **and** the ID, face visible.
3. **Proof of address** — recent utility bills and/or bank statements (policy: two different copies).
4. **Security phone** — the address step may ask to confirm a contact number / verify a code if a Security Phone Number is not already set.

Entry the policy names: Profile → Settings → Account Details → **Verify my Identity**.

Review, when someone actually submits, is on Freelancer’s side (policy: business days). This pack never submits.
