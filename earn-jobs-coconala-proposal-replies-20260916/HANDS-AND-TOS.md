# HANDS + 規約 — ココナラ JOBS 期（自動返信なし）

**HANDS** とは: 相談を読む、この件だけの1行を直す、公式の返信欄へ貼る、**自分が** 送信または辞退を押す。コンピュータが送信してはいけない。

JOBS PHASE は出品公開のあとに届く **問い合わせ** と **見積り・カスタマイズ相談** だけを扱う。登録・KYC・出品本文は別パック。

## このパックで禁止（後から足さない）

書かない、動かさない:

- 新着監視ボット、ヘッドレスブラウザ、スクレイパー、拡張での自動返信
- 定型文の無人送信（公式の定型文は人が挿入してよい。この PR は挿入もしない）
- 見積り期限リマインドへの自動「提案」
- 複数アカウント、評価操作、不特定フォロー
- 事前のメール・電話・LINE・X・QR
- サイト外決済、成果報酬の独自払い、振込先の案内
- git に入れた実在の円・納期・手数料率
- 収益・受注・時短の保証文

購入者が先に外の連絡先を書いてきても、**誘導に応じない。** ルールとマナーは双方に掛かる。
