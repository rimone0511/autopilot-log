# 活動ゲート（チェックリストのみ）

対象: QUEUE Wave D の `needs_activity_check`。Wave C に「High では？」と新規追加する前にも使う。  
**数値を作らない。** 公式が出していない件数・GMV・成約率・「月収」を書かない。

合格するまで登録しない。合格しても **下書きのみ**。公開しない。

## 使うとき

- Wave D の机を 1 つ開く
- 未知の机を High/Med に足したくなったとき
- Wave B の AI CrowdWorks など、入口が開いているか疑わしいとき

1 回 1 机。MAIN Google で **ログインする前に** 公開ページを見る。ログインが必要な項目は、その旨を書いて止めてよい。

## チェックリスト

各項目は `yes` / `no` / `unknown`。`unknown` は不合格（登録しない）。

### 1. 机が生きている

- [ ] 公式 URL が開き、ブランドが机の名前と一致する
- [ ] 閉鎖文・「サービス終了」・ドメインパーキングではない
- [ ] 売り手／人材／メンター／出品者の登録導線がある（発注者だけではない）

`no` → [SKIP.md](SKIP.md) の閉じた机 or 薄い机。

### 2. 寄せ集めではない

- [ ] 応募・出品先が **このサービスの中** にある
- [ ] 外部求人サイトへ飛ばすだけの一覧ではない

`no` → SKIP の aggregators-only。LinkedIn Jobs と LinkedIn Services を混ぜない。

### 3. 現地労働だけではない

- [ ] リモート／オンライン納品の道がある（またはデジタル配布）
- [ ] シフト・店舗・単発バイト専用ではない

`no` → SKIP の現地労働。

### 4. 本人専用クラスではない

- [ ] Mercor / Outlier / DataAnnotation 型の「本人の試験・身分専用」ではない
- [ ] エージェントが代わりにアカウントを作れ、という設計ではない

`no` → SKIP の本人専用。

### 5. 活動の目視（数字なし）

見たものを短く書く。件数を推定しない。

- [ ] 公開の募集・サービス・チケット・プロフィールの **どれか** が画面にある
- [ ] 「新しさ」の手がかりがある（日付表示、新着、最終ログイン表示、など）。手がかりが無ければ `unknown`
- [ ] スパム複製だけで本線（自動化・制作・相談・デジタル配布）が皆無、ではない

手がかりが無い／スパムだけ → SKIP thin。

### 6. 認証・KYC（登録する直前）

ここまで合格してからログインを検討。

- [ ] MAIN Google で入れる、またはメール登録のみ（別アカウントを作らない）
- [ ] 登録直後に免許・パスポート・顔写真を求められない。求められたら **アップロードせず停止**（朝の本人）
- [ ] 公開トグルを触らなくて登録できる（下書きで止まれる）

KYC 必須 → 登録しない。SKIP ではなく QUEUE に「KYC待ち・朝の本人」。

### 7. 本線との噛み合わせ（主観を明示）

- [ ] 日本語または英語の客に、自動化／制作／相談／デジタル配布のどれかを置ける
- [ ] コンテスト専業・現地のみ・求人ボードのみ、ではない

噛み合わない → SKIP thin（理由を 1 行）。

## 記録テンプレ（コピーして使う）

秘密・スクショ実ファイル・個人情報をリポジトリに置かない。

```
日付（JST）:
机:
公式URL:
公開ページを見たか: yes/no
ログインしたか: no（推奨） / yes-MAIN-Google
1 生きている: yes/no/unknown
2 寄せ集めではない: yes/no/unknown
3 現地だけではない: yes/no/unknown
4 本人専用ではない: yes/no/unknown
5 活動の目視: yes/no/unknown
   見たもの:
6 KYC: 出ていない / 出て停止
7 本線: yes/no
判定: pass / fail-closed / fail-thin / fail-aggregator / fail-local / fail-identity / fail-kyc-stop
QUEUE: Wave C に1行 / Wave D のまま / SKIP へ移動
公開したか: no
```

## 判定

| 判定 | 次 |
|---|---|
| 全部 `yes`（6 は「出ていない」） | 登録可。Wave D なら Wave C 末尾か「Med 合格」メモ。**Wave A には上げない** |
| fail-closed | SKIP 閉じた机 |
| fail-aggregator | SKIP 寄せ集め |
| fail-local | SKIP 現地労働 |
| fail-identity | SKIP 本人専用 |
| fail-thin | SKIP 薄い机 |
| fail-kyc-stop | 登録しない。朝の本人。SKIP ではない |
| `unknown` が1つでも | 不合格。推測で pass にしない |

## 禁止

- 案件数・ワーカー数・「稼げる」の創作
- 公式に無いランキングの引用を根拠にすること
- ゲート前の登録
- KYC の代行
- 出品公開
