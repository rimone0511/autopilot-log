## 禁止（このフォルダの目的外）

- 実在の依頼者名・会社名・募集URL・案件IDを書かない（架空ラベルのみ。本パックは `依頼者F`–`依頼者Q`）
- 提案・見積もり・メッセージの **送信**
- 秘密（メール全文、鍵、パスワード、口座、本人確認、非公開マニュアル）
- 未確認の件数・年数・短縮分数・受注率・精度％
- **収入・収益・受注・時短の保証**（見通しも書かない）
- ブラウザ自動操作、スクレイピング、いいね／フォロー／閲覧の自動化
- 権利のない投稿代行
- 金額・納期の確定（プレースホルダのまま。本人が案件を読んでから書く）

## 使ってよいこと

1. 案件を読んだ人が、該当する 1 本を選ぶ。
2. プレースホルダを **ローカル台帳** で置換する。この PR に実値を足さない。
3. 一覧冒頭・短文・標準文の文字数を画面カウンタで再確認する。
4. 本人が文面を直す。送信は別の人間作業。このパックからは送らない。

## 文体（3 机共通）

- ですます調。1 文は短く。
- 一覧の先頭は「はじめまして」より、案件の理解を先に出す。
- 未確認の実績件数を書かない。公開 URL だけを根拠にする。
- 「必ず成果が出ます」「何でもできます」「稼げる」は使わない。
- 範囲外を本文に 1 ブロック置く（契約前の食い違いを減らす）。
- 秘密はチャットに貼らせない。権限は依頼者側。

- 未確認のままの公開（公開スイッチは依頼者または本人）
