# HANDS + ToS — Contra Independent JOBS phase (no auto-apply)

**HANDS** means: you read **one** job, you rewrite the one specific line, you paste in the official Apply / proposal fields, you click Apply. A computer must not be the thing that submits.

**Surgical** means: **one listing per style file**, then stop. “Make applying a habit” in Contra’s first-client help is marketing, not a spray instruction. Identical first paragraphs across jobs are spray.

Default: **do not send**. This pack does not sign up, buy Pro, open wallet, or click Apply.

Sibling CU (`draft_saved`, apply: no) is not overridden here.

## Forbidden in this pack (do not add later either)

Do **not** write or run:

- Auto-apply / bulk Job-feed queues / “apply to more posts” scripts
- Browser automation, headless browsers, scrapers, or extensions that submit faster than a person
- Third-party “Contra auto-proposal” tools or inbox crawlers
- Multiple accounts to dodge rate limits
- Substantially identical applications blasted across opportunities
- **Refer & Earn** outreach from this pack (official help opens DMs that can go on **or off** Contra)
- Contra Labs / Expert-program / Discover-boost applications from this pack
- Contact info (email, phone, WhatsApp, Telegram, Slack) in a pre-contract application
- Off-platform payment instructions
- Live USD amounts committed in git
- Paid-project **fee tables**, Pro list prices, or processing-fee amounts copied into git — **help URLs only**

Native saved replies (if the UI shows them) are still templates you insert by hand; personalize `{{ONE_SPECIFIC_DETAIL}}` before send.
