# HANDS + ToS — no off-platform pay

Status: **DRAFT_ONLY**. 人が公式 UI に貼る。ボットで応募・出品しない。

**HANDS** = 画面を読む → このパックを貼る → 公開ボタンは人が押さない（下書き保存まで）。提出スクリプトは置かない。

## Forbidden in this folder

- サイト外の支払い（現金、銀行振込、PayPal、暗号、別サイトの請求書）
- メール / 電話 / LINE / WhatsApp / Slack を **契約前の本文・プロフィール・スキル欄** に書く
- 中抜き・直接取引の勧誘
- 自動応募、同一文面の大量送信、スクレイピング
- 第二アカウント
- 料金・手数料・時給の創作、売上実績の創作
- Craudia PRO を手数料対策で買うこと
- スキル出品を「プロフィールの代わり」にすること

## クラウディア

公式:

- [直接取引について](https://www.craudia.com/faq/contents/164)
- [相手との連絡で禁止されていること](https://www.craudia.com/app/faq/contents/140)
- [利用規約](https://www.craudia.com/app/agreement)（第8条5 他サイト誘導。第12条4–5 直接取引。第10条 手数料）
- [仕事受発注ガイドライン](https://www.craudia.com/project_guideline)
- [ワーカー用ガイド](https://www.craudia.com/app/guide/crowd-sourcing/worker)（応募とスキル出品。どちらもこのパックでは開始しない）

禁止の要旨:

- サイトを介さない依頼・受注・金銭取引は直接取引として禁止（FAQ 164）
- クラウディア以外のツールでの「直接連絡」の勧誘も禁止。必要なときだけ公式の **サービス外連絡申請**（FAQ 140）。このパックは申請しない（応募も出品もしないため申請口に入らない）
- 規約第12条5: 直接契約した場合の違約金は報酬の **30%**（下限 **100万円**）— **数字は規約本文を正とする。ここでは警告だけ**
- プロフィールや応募にメール・電話・「この口座へ」を書かない（ガイドライン NG 例）
- いいね・星5レビュー・他社規約違反の代行を受けない（ガイドライン）
- 常駐・通勤前提の仕事はガイドラインがオンライン完結が難しい仕事として NG 例に出す。このパックは応募しない

このパックは応募もスキル出品もしないので、メッセージ発生前に止まる。

## Allowed

- 下書きとプレースホルダ
- 公開ポートフォリオ / GitHub の URL（スキルの実物。mailto にしない）
- 範囲外（スクレイピング、エンゲージメント詐欺、オフプラットフォーム支払い）の仕事を断ること
- KYC（書類+自撮り）で止めること
- スキル出品をしないこと

## Jobs this seller declines

- 公式 API の無いブラウザ自動化・スクレイピング
- 相手の公開ゲート無しの SNS 投稿代行
- 別国籍の詐称
- クラウディア外の直接支払い
- ステルスマーケティング・偽レビュー
