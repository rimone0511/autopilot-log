# Fiverr — STOP before KYC

Desk: Fiverr
Mode: DRAFT ONLY
Pack date: 2026-09-16

Fiverr help states that **personal and business information verification is required
before publishing the first Gig**, and that **phone verification is required before
publish**. This pack never publishes, so those gates are not a reason to upload ID.

If the live form **refuses to save a draft** without identity documents, **stop**.
Hand the desk name and the screen type to the morning operator. Do not upload.

## Allowed for this pack

- [ ] MAIN Google signup / login as `{{GOOGLE_ACCOUNT_EMAIL}}`
- [ ] Email verification code from the inbox (do not paste the code in git or chat logs)
- [ ] Become a Seller / freelancer onboarding videos
- [ ] Individual (not Agency / Team) profile fields with placeholders
- [ ] Create a Gig on **desktop** and fill [GIG-PASTE.md](GIG-PASTE.md)
- [ ] Leave the Gig in **Draft** (or equivalent unpublished status)

## Hard stop — do NOT

Identity and tax (KYC):

- [ ] Click **Verify** on Identity Verification or Personal & Business Info
- [ ] Upload government photo ID (passport, driver's license, My Number card, residence card)
- [ ] Take or upload a selfie / liveness photo for ID matching
- [ ] Upload proof of address
- [ ] Type a national ID number, My Number, tax ID, or business registration number
- [ ] Submit W-9 (US). Operator country is not the US; do not claim US person
- [ ] Submit DAC7 or other tax forms
- [ ] Send ID photos to Fiverr Support (help says Support cannot verify you that way)

Payments and paid plans:

- [ ] Add a credit card or PayPal to enroll in **Seller Plus Kickstart** ($15/month)
- [ ] Buy Promoted Gigs, featured listing, or other boosts
- [ ] Enter bank / withdrawal details

Publish:

- [ ] Click **Publish Gig**
- [ ] Switch the Gig from Draft / paused to active
- [ ] Make the freelancer profile publicly searchable if a later screen offers that as a publish step tied to KYC

Phone:

- [ ] Phone SMS for **account recovery** is not the same as ID upload. If onboarding blocks even a Gig **draft** without SMS, the morning operator may complete SMS on a device they control, then stop. If the phone step asks for ID, selfie, or a paid ID vendor, treat it as KYC and **stop**.
- [ ] Do not type `{{PHONE_E164}}` into git.

## If KYC appears

1. Close the upload dialog. Do not choose a file.
2. Leave the Gig in Draft if it already saved.
3. Record only: date, desk `Fiverr`, screen name (Identity Verification / tax form / other).
4. Morning operator decides. This pack is complete as unpublished paste.

Do not store screenshots that show ID, face, or full account email in the repo.
