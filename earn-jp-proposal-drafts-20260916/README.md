## 文体（3 机共通）

- ですます調。1 文は短く。
- 一覧の先頭は「はじめまして」より、案件の理解を先に出す。
- 未確認の実績件数を書かない。公開 URL だけを根拠にする。
- 「必ず成果が出ます」「何でもできます」は使わない。
- 範囲外を本文に 1 ブロック置く（契約前の食い違いを減らす）。
- 秘密はチャットに貼らせない。権限は依頼者側。

- パスワード・API 鍵・本人確認書類の代理入力
