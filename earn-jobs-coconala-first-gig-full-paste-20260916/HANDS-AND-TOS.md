# HANDS + ToS — stay on Coconala

Status: **DRAFT_ONLY**. 人が公式 UI に貼る。ボットで公開・購入・見積もり送信しない。

**HANDS** = 画面を読む → このパックを貼る → **下書き保存まで**。公開スクリプトは置かない。

## Forbidden in this folder

- サイト外の支払い（現金、銀行振込、PayPal、暗号、別サイトの請求書）
- LINE / Skype / Zoom / メールアドレス / 電話番号を **サービス本文・キャッチ・FAQ・お願い** に書く
- 中抜き・直接取引の勧誘
- 自動応募、同一文面の大量送信、スクレイピング
- 第二アカウント
- 料金・手数料・販売件数の創作
- 有料オプションを購入必須にする（公式マグが禁止と書く）
- セラーサクセスを文字数のためだけに買う
